# Kimyo mock · Milliy sertifikat

O‘quvchilar uchun mock test sayti: 12 ta Milliy sertifikat (kimyo) varianti, avtomatik baholash,
har bir savolning yechimi va natijani o‘qituvchiga Telegram orqali yuborish.

Bu repozitoriyda faqat yig‘ilgan (build) sayt bor. U GitHub Pages orqali ochiladi:
**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**

Yangilash: Spektr loyihasida `npm run build:oquvchi`, so‘ng `dist-oquvchi/` ichidagi fayllarni shu repoga nusxalab push qilish.
